# Лабораторная 3 — RSA

## Задание

- Вычисление открытого ключа **KO** (e) по простым **p**, **q** и закрытому **KС** (d) — расширенный алгоритм Евклида.
- Побайтовое шифрование файла: `c = m^KO mod r`, каждый блок **16 бит** (2 байта) в файле.
- Вывод зашифрованного содержимого на экран **в десятичной системе**.
- Дешифрование: параметры **r**, **KС**; блоки по 16 бит → байты: `m = c^KС mod r`.
- Быстрое возведение в степень по модулю.

## Запуск

Из корня репозитория: `python3 -m http.server 8080` → http://localhost:8080/lab03/

```bash
cd lab03 && node test-rsa.mjs
```

## Проверки параметров

- p, q — различные простые числа
- r = p·q > 255
- 1 < KС < φ(r), НОД(KС, φ(r)) = 1
- каждый байт сообщения < r
